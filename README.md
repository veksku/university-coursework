## Working with a course

Each course has its own directory. Open that directory and follow its README or project files for setup and usage. Build and run commands should be executed from the relevant course directory.

## Repository history

These 22 course repositories were consolidated with their original commits intact. Each course directory contains its original default-branch snapshot at the time of import.

Original branches are preserved as `source/<original-repository>/<original-branch>`. Those branches retain their original directory layout. The `migration-manifest.json` file records the source snapshots and branch references.

Course-specific licenses remain with their original files.
